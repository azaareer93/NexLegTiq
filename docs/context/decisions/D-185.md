MVP-119 left open where the guides are published, how support is reached and which shortcuts exist. → **Where:** in the
office app at `/help` (every signed-in user), not public Notion pages or a separate site: one place, always in both
languages, and each guide can sit next to the page it explains. **Content:** 13 guides (getting started, invite team,
create a case, parties and conflicts, hearings and reminders, documents and search, tasks, AI summaries — with the
disclaimer and the monthly limit —, time and invoicing, client portal — said to be coming, as it is not built —, roles
and permissions, data export, security and privacy), each a title, a summary, paragraphs (`\n\n`) and numbered steps
(one per line) in the `help` namespace — plain strings, so the ar/en parity checks cover them; no markdown dependency.
**Help:** the profile menu's "Help"; the page lists the guides, the keyboard shortcuts that exist (Ctrl/⌘ + K search,
Ctrl + Alt + N new case) and support: email, WhatsApp (`https://wa.me/<digits>`) and "Report a problem" (a mailto with
the page path, language and time — never page data — and a prompt for the error's reference), from
**`VITE_SUPPORT_EMAIL` / `VITE_SUPPORT_WHATSAPP`** (a channel left unset is not offered). **"?" links** (`HelpLink`) beside
the titles of Cases, Calendar, Tasks, Invoices and Settings open their guide. **Link check:** a test asserts every guide
has its four fields in both languages, and `HelpLink`'s slug is typed to the guide list. **Not done:** screenshots from
demo data (to add once the screens settle), editing the Notion FAQ to match (the owner's spec page), a public help site.
