**D-172 — Search overlay: what each result opens, "see all" in the overlay, recent searches in memory only** · Accepted (MVP-82, 2026-11-14)
MVP-82 left what a result opens, where "see all in <type>" leads and where recent searches are kept open. → The shell's
search button and Ctrl/Cmd+K (D-091) open `SearchPanel` (`apps/office-app/src/features/search`) on `GET /search` (D-167,
`searchApi` in shared-api-client): the query waits 300 ms after typing stops and needs 2 characters; groups Cases, Clients,
Documents, Tasks, 5 each, in that order. **Opens:** a case → `/cases/:id`; a client → the client profile (D-168); a document
→ its file's Documents tab; a task → its file's Tasks tab, or `/tasks` for a personal task. **Parties are not shown** — a party
has no page of its own to open (the API still returns them). **"See all in <type>"** (shown while the API says `hasMore`)
asks for that type alone with the API's maximum of 20 inside the overlay, with "back to all results"; there is no page beyond
20 (the case and client lists search differently, D-096/D-108). **Keyboard:** the input is a combobox over one listbox —
arrow keys move (wrapping), Enter opens, Escape closes; the result count (Arabic plural forms) or "nothing found" is
announced in a status region. Document snippets show the API's matches as `<mark>` text, never HTML (D-167); file numbers
are left to right. **Recent searches** (the last 5, a search is remembered when a result is opened) are kept **in memory only**,
for the user who made them — not in localStorage, which the ticket allowed: a query can name a client and office computers are
shared (D-087's rule for the language choice); they are gone on reload. **Not done:** the Cypress journey (E2E story; every
control has a `data-testid`), searching witness statements (D-167).
Review additions (same PR): a new query leaves "see all" at once (no request for the old type), Enter is ignored while the
300 ms wait is running (it would open a result of the previous query), the input stops at the API's 200 characters, "see all"
and "back" are plain text inside their options (an option holds no nested link), and the listbox is named "Search results".
