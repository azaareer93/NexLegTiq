**D-184 — Data export: an office ZIP built in the background, downloaded through short links; a user's own data as JSON** · Accepted (MVP-106, 2026-11-15) · Builds on D-013, D-084, D-035

MVP-106 left open how the emailed link fits D-013 (download links last 15 minutes), what the ZIP holds and how the
user-level export works. → **Office export** (`export:office`, OM; allowed while the office is read-only — a lapsed
office still owns its data): `POST /offices/me/export` → 202 with an `office_exports` row (QUEUED; one at a time — the
one being prepared is returned) and an `EXPORT` audit row; the `report` queue's `office-export` job (in the office's
tenant context) builds a ZIP with **yazl** (new dependency, streaming, no transitive deps): `data/<entity>.json` for every
entity (office, settings, users **without secrets**, clients, files, file clients/team, parties, sessions, tasks,
folders, documents' metadata, notes, time entries, invoices and lines, retainer entries, witnesses and statements,
timeline, the newest 50,000 audit rows without IP/user agent), `csv/{files,clients,invoices,timeEntries}.csv` (BOM,
quoted, formula-defused), every live READY document under `documents/<file number>/<folders>/<id>-<name>`, and
`manifest.json` (SHA-256 and size of each entry; documents' from their upload). The ZIP streams to
`{officeId}/exports/{id}.zip` (server-side encryption when configured, D-035), its own SHA-256 and size recorded; READY
for **7 days**. The email (`export-ready`) links to **Settings**, never to the file: there `GET
/offices/me/exports/:id/download` gives a **15-minute** link each time (D-013), audited `DOWNLOAD`; not ready, failed or
expired → **422 BIZ-026 (new)**. `GET /offices/me/exports` lists the latest 10. **User export:** `GET /users/me/export`
(any user, 5/hour) → the caller's profile, tasks (assigned or created), time entries, notes written and their newest
5,000 audit rows, in the envelope; the app saves it as `my-nexlegtiq-data.json`; audited `EXPORT`. **UI:** Settings →
Data (request, statuses, download, polled while preparing) and Profile → "Download my data". **Not done:** deleting
expired ZIPs (a storage lifecycle rule on `*/exports/` is the plan — `shortcut:`), paging each entity's JSON for very
large offices, PDF summaries; office deletion stays MVP-152.
